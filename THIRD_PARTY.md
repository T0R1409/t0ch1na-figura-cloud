Build-only dependencies (not bundled in player JARs):
- Fabric Loader API: https://github.com/FabricMC/fabric-loader
- Minecraft Forge Java FML language API: https://github.com/MinecraftForge/MinecraftForge
- NeoForge/FancyModLoader APIs: https://github.com/neoforged/FancyModLoader
- Sponge Mixin: https://github.com/SpongePowered/Mixin
- Gson: https://github.com/google/gson (provided at runtime by Minecraft)
- Eclipse Java compiler: https://projects.eclipse.org/projects/eclipse.jdt

Runtime host dependency: aiohttp, installed in the backend Docker image.
Figura is a separate required mod, not redistributed in AutoCloud.
